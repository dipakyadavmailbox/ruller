# Agent Rules & Configuration

## MCP Server Configurations
When needing to query official Astro framework documentation, use or refer to the Astro Docs MCP HTTP server:

```json
{
  "mcpServers": {
    "Astro docs": {
      "type": "http",
      "url": "https://mcp.docs.astro.build/mcp"
    }
  }
}
```
