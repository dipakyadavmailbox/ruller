*Prepared for affiliate program applications and advertiser partnership requests.*

## About Rocking Tools

Rocking Tools is a small collection of single-purpose web utilities — no
signup, no clutter, no dark patterns. Each tool solves exactly one
well-defined problem a person is actively searching for a solution to
the moment they land on the page:

- **Screen Ruler** — an on-screen ruler calibrated to true physical
  scale (mm/cm/inches), accurate even as the browser is zoomed.
- **Password Strength Checker** — instant password strength, entropy,
  and crack-time analysis, plus a secure password generator. Every
  calculation runs client-side; passwords are never transmitted,
  logged, or stored.
- **Calorie Calculator** — a TDEE and macro-split calculator using the
  Mifflin-St Jeor equation, the formula generally regarded as most
  accurate for healthy adults.

## Why Partner With Us

- **High-intent placement.** Recommendations appear at the exact moment
  a visitor has just learned something actionable about themselves —
  e.g., a password manager pitch right after someone sees their
  password is weak, or a kitchen scale/supplement recommendation right
  after someone gets their daily macro targets. This is a fundamentally
  different (and typically higher-converting) context than a banner ad
  shown to a passive reader.
- **Trust-forward design.** The password tool's headline claim — "your
  password never leaves your browser" — is both true and a genuine
  differentiator; many competing tools in this space quietly log
  submitted passwords. Trust-based tools tend to see better
  affiliate-link click-through because visitors already believe the
  site is acting in their interest.
- **Built for cross-promotion.** All three tools share one domain, one
  navigation, and a home page that links to all of them, so visitors
  arriving via one tool's search traffic are one click from the others
  — improving pages-per-session and total affiliate impressions per
  visitor versus a single-tool competitor site.
- **Technical foundation.** Lightweight React build with no unnecessary
  dependencies, built with Core Web Vitals and mobile performance in
  mind from day one.
- **Validated categories.** Each of these three tool categories already
  has a dozen-plus established, actively maintained competitor sites —
  that density of competition is itself a signal of durable, real
  search demand, not a speculative niche.

## Business Goals

**Near term (0–3 months):** launch, get all three tools indexed, and
use early analytics to learn which tool converts best per visitor for
which affiliate categories (password managers vs. health/fitness
products vs. general tools).

**Mid term (3–9 months):** build supporting content around each tool
(comparison guides, "how to choose a password manager," "how accurate
is TDEE," etc.) to capture higher-intent, higher-commercial-value
keyword variants beyond the core calculator/checker terms.

**Long term:** grow into a recognizable small "utility tools" brand
with repeat visits, and diversify monetization across display
advertising, affiliate commissions, and potentially a small set of
premium/pro features for power users.
